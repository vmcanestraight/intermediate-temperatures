# intermediate-temperatures
Code and data for the manuscript "Intermediate Temperatures in Electrochemical Synthesis: Data and Theory-Backed Motivation

The code is divided into two sections, one dedicated to the construction and analysis of an industrial dataset and one for simple plotting and analysis of data. The structure is more thoroughly documented in the supporting information of this publication.

We intend to use Zenodo to create a stable release of this repository upon publication.

## Installation and Dependencies
Because this code is not a general tool to apply to data generated by other researchers, it is formatted in jupyter notebooks. Thus, it is not traditionally installed. Other researchers are welcome to download the necessary jupyter notebooks and data to reproduce our analyses or explore other data we chose not to analyze in our text.

To run this code, it is recommended to use an python environment manager such as Anaconda and create a new environment with the provided .YML files. Creating these environments should take <10 minutes on a typical laptop.

## Demo
Because this code does not generalize to other datasets, there is no simplified demo, and the notebooks themselves serve as the demo.
